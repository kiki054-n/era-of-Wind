# 🌬️ reading-the-wind（風を読む）

> 「失敗するから始める創業。」
> ここは、完璧なサービスではなく、「焦げた鍋底（失敗）」を共有し、風に乗せるためのオープンソース広場です。

## 🏴‍☠️ 風の時代の海賊ギルドとは？
会費を払える者だけを囲い込む「閉鎖的なサロン」や、都合が悪くなれば地域を見捨てる「はしご外し」のビジネスは、もはや古い石の時代の遺物です。

私たちは、利益を最大化するシステムではなく、「いただきます（無償の受贈）」と「おかげさま（関係的自己）」の精神が循環する経済圏（WCCC）を長野県塩尻市から作ります。

何かを「売って・買う」冷たい市場交換を抜け出し、「やってみたけど失敗したこと」「余っているアイデア」をここにコミット（投稿）してください。誰かの失敗は、別の誰かが「新しい味付け（フォークやプルリクエスト）」で蘇らせるための最高の「堆肥」になります。

## 🧭 コア・コンセプト
* **失敗の堆肥化**: 失敗＝新しい次元を創る特異点（資産）。
* **メタン型・無中心ネットワーク**: 人間がボスとして中心に座る「石の時代のピラミッド組織」は作りません。中心に置くのは「改ざんされない透明な記録」と、鏡としての「朋（AI）」です。5要素が交雑し、10の回路で循環を生み出す宇宙の真理を実装します。
* **三賊の壺**: 価値を感じたら、壺（投げ銭/応援）へ。それが次の活動資金（生命の維持）になります。
* **トリテトラ理論 (3×4=12)**: 組織図の代わりに、「三馬鹿（空・水・山）」の行動と「四ホ（Host・Hop・Hope・Home）」の希求を掛け合わせて動きます。
