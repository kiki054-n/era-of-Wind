# 🏴‍☠️ 海賊のためのGitHub用語辞典（馬鹿専用・超入門）

ようこそ！ここは「コードが1行も書けない人間」が、己の失敗を笑い飛ばし、世界をあっと言わせるためのオープンソース広場です。

お高く留まったプログラマーたちが使う「呪文（IT用語）」は、今日からすべて海賊の言葉にアンラーン（学習棄却）します。この辞典さえ読めば、あなたも立派な「風を読む海賊」です。

## 📖 基本用語（アンラーン版）

* **Repository（リポジトリ） ＝ 「焚き火」または「三賊の壺」**
  皆が集まって、持ち寄った失敗やアイデアを放り込む場所。この `era-of-wind` のことです。

* **Commit（コミット） ＝ 「懺悔（ざんげ）」**
  自分の失敗（焦げた鍋底）や馬鹿な思いつきをテキストに書き、とりあえず保存すること。ここでは恥をかくほど偉い。

* **Push（プッシュ） ＝ 「風に乗せる」**
  書いた懺悔を、世界に向けて大声で叫ぶ（Web上に公開する）こと。風に飛ばされたら、もう後戻りはできません。

* **Fork（フォーク） ＝ 「パクリと魔改造」**
  他人の面白い失敗を自分の手元にコピーして、勝手にヤバいアイデアを付け足すこと。ここでは「パクられること」が最大の誉れです。

* **Pull Request（プルリク） ＝ 「馬鹿の出口提案」**
  「お前の失敗、こうやったらもっと面白くなるぜ！」と、元ネタの持ち主に絡みに行くこと。愛のある最高のお節介。

* **Merge（マージ） ＝ 「乾杯（発酵）」**
  他人のヤバいアイデア（プルリク）を受け入れて、自分のプロジェクトと混ぜ合わせること。グラスを鳴らした瞬間、新しい価値が発酵します。

* **Issue（イシュー） ＝ 「御触れ（おふれ）」**
  「こんな馬鹿なこと思いついたんだけど、誰か一緒にやらない？」「今度ハナレでワイン会やるぞ！」という呼びかけ・掲示板。

### 🍷 最大の掟（エラールール）

GitHubを使っていると、画面が真っ赤になったり、謎の英語のエラーが出たりして、取り返しのつかないミス（ファイルを消す等）をすることが必ずあります。

**その時の唯一の対処法：**
**「ギャハハ！なんか壊れた！」と笑い、とりあえずワインを一杯飲む。**

プログラマーの世界では「エラー」は罪ですが、OπO大学では「エラー（失敗）＝極上の酒の肴」です。
分からなくなったら、塩尻のハナレにPCを持ち込んで、3馬鹿の誰かに泣きつきましょう。
さあ、恐れずに最初の「懺悔（コミット）」を風に乗せてください！
