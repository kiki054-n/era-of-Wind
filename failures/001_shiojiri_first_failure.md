# 🏴‍☠️ [失敗録001] 善意のネズミ講と消えた壺の底（プラットフォーム手数料の罠）

## 1. 何を企んだか？（The Plan）
**「メンバー増殖のための、500円エントリー＆バックシステム」**
ギルドの仲間を増やすために、シンプルなインセンティブ設計を企みました。
仕組みはこうです。
1. 新規メンバーは「三賊の壺」にエントリーフィーとして500円を入れる。
2. 誰かを新しくギルドに紹介・加入させたら、壺からその人に500円をバックする。
要するに、包み隠さず言えば**「善意のネズミ講」**です。これをnoteの会員登録（メンバーシップ）機能を使ってスマートに実装しようとしました。

## 2. どのように豪快に失敗したか？（The Disaster）
**「壺の底が抜けていた（回せば回すほど赤字）」**
note上でいざ運用を始めようと計算したところで、致命的な事実に気づきました。
noteの決済には「プラットフォーム手数料（約10〜15%）」がかかるのです。

つまり、メンバーが500円をnote経由で支払っても、壺に入るのは約425円。しかし、紹介者へのバックは「500円」と約束しています。
結果として、**「人が加入して盛り上がれば盛り上がるほど、壺の中身がマイナスになっていく」**という、前代未聞の自己破壊型システムが完成してしまいました。

## 3. なぜ失敗したのか？（The Wind We Missed）
**「Web2（中央集権）の関所を甘く見ていた」**
私たちは「いただきます」と「おかげさま」の贈与経済（WCCC）を回そうとしましたが、それを市場経済のど真ん中である「中央集権プラットフォーム（note）」の決済システムに乗せてしまいました。
現代のシステムには必ず「関所（手数料）」があり、そこで血（資金）が抜かれるという物理法則（風）を完全に読み違えていました。

## 4. この焦げた鍋底（失敗）に、どんな旨味が残っているか？（The Compost）
**「コモンズの壺は、手渡しか、手数料ゼロの場所で作るべし」**
この失敗は、「贈与経済を既存のプラットフォームに依存して実装しようとすると、数学的に破綻する」という非常に価値のある実証データです。
この鍋底の焦げ跡からは、以下のアイデアが発酵しそうです。

* **フォーク案A**: 壺を完全に物理（塩尻のハナレに置いたリアルな壺や賽銭箱）にする。
* **フォーク案B**: 手数料の概念がない独自の地域通貨、または暗号資産（トークン）で壺を再設計する。
* **フォーク案C**: そもそも「500円」という法定通貨のやり取りをやめ、「野菜」や「スキル」などの現物支給のネズミ講にする。
